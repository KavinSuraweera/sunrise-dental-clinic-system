# Sunrise Dental Clinic Management System

A secure web-based appointment, patient and billing management system developed for Sunrise Dental Clinic in Colombo.

## Planned Features

- Secure staff authentication
- Role-based authorization
- Patient registration and management
- Appointment registration
- Dentist double-booking prevention
- Appointment search
- Treatment and consultation fee calculation
- Printable patient receipts
- Management reports
- Staff help section
- REST web services
- Automated testing
- CI/CD deployment

## Technology Stack

- Java 21
- Spring Boot 4.1.1
- Spring Security
- Spring Data JPA
- Thymeleaf
- PostgreSQL
- Flyway
- Maven
- Docker
- GitHub Actions

## Architecture

The application follows a three-tier architecture:

1. Presentation tier
2. Business logic tier
3. Data access tier
